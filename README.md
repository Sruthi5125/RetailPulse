# RetailPulse – Demand Forecasting & Inventory Optimization

RetailPulse is a data analytics project that analyzes retail sales data to understand demand patterns and forecast future product demand. The project also converts forecast results into inventory decision metrics to support better inventory planning.

## Objective
The goal of the project is to:
- Analyze historical retail sales data
- Identify demand trends and seasonality
- Forecast future demand using time-series models
- Provide insights for inventory planning

## Dataset
The project uses the **Global Superstore dataset** containing over **50,000 retail transaction records**.  
The data was aggregated into **monthly demand by product category** for analysis and forecasting.

## Tools & Technologies
- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- SARIMA (Statsmodels) for time-series forecasting  
- Scikit-learn (MAPE for model evaluation)  
- Power BI for dashboard visualization

## Workflow
1. Data loading and preprocessing  
2. Exploratory Data Analysis (EDA)  
3. SARIMA time-series demand forecasting  
4. Model evaluation using MAPE  
5. Inventory metrics calculation (Safety Stock & Reorder Point)  
6. Visualization using Power BI dashboard

## Outcome
The project identifies demand trends, seasonal patterns, and generates demand forecasts that can help retailers make better **inventory planning decisions**.
